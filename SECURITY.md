# Security policy

## Scope

This repository is a research-only library. It has no exchange connector, wallet
support, account access, network client, deployment configuration, or order
execution path.

Do not add credentials, private endpoints, real account data, raw vendor data, or
environment files. All committed examples must be generated from synthetic data.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting:

https://github.com/springtiming/hypertrader-research-platform/security/advisories/new

Do not include a credential or sensitive dataset in a public issue. If a secret is
ever committed, revoke or rotate it before attempting repository cleanup.

## Supported versions

Only the latest release on the default branch is supported.
